# Architecture Decision Records

ADRs capture material technical choices that affect how BiasLens is built or operated.

## When To Write One

- A platform or architecture decision changes system constraints
- A new dependency or infrastructure pattern introduces long-term coupling
- A security, compliance, or operational tradeoff needs durable context

- [0001-monorepo-strategy.md](0001-monorepo-strategy.md)
- [0002-service-separation.md](0002-service-separation.md)

## Template

```text
# ADR NNNN: Title

## Status
Accepted | Superseded | Proposed

## Context
What problem are we solving?

## Decision
What did we choose?

## Consequences
What becomes easier, harder, or riskier?
```
