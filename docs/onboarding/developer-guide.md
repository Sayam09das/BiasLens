# Developer Guide

## First Week Path

1. Read the root [README.md](../../README.md) and [System Overview](../architecture/00-system-overview.md).
2. Start the platform locally with `make dev-up` or run services individually.
3. Review service-specific package files and test commands.
4. Read the ADRs before changing architecture or infra assumptions.

## Team Conventions

- Keep changes scoped to the owning service when possible.
- Update documentation with operational or architectural changes.
- Prefer tests near the layer being modified.
