# SLO And SLA

## Service Objectives

- Availability target: 99.9% for core audit and reporting workflows
- P95 backend API latency: under 500 ms for non-ML endpoints
- P95 ML analysis latency: under 3 seconds for standard single-resume analysis
- Error budget: 43.2 minutes of monthly unavailability at 99.9%

## Notes

- These are initial operating targets, not contractual commitments.
- Error-budget consumption should influence rollout pace and incident review depth.
