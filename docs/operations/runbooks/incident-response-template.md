# Incident Response Template

## Severity

- `SEV-1`: platform unavailable or materially incorrect audit outcomes
- `SEV-2`: major degradation with workaround
- `SEV-3`: localized issue or partial loss of non-critical capability

## Immediate Workflow

1. Declare incident channel and incident commander.
2. Record impact, start time, and affected capabilities.
3. Stabilize first: rollback, scale, disable feature flag, or isolate dependency.
4. Capture evidence: logs, traces, metrics, deployment IDs, and recent config changes.
5. Communicate user impact and next update time.
