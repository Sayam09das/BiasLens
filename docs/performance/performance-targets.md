# Performance Targets

## Platform Targets

- Public page LCP under 2.5 seconds on broadband desktop
- Dashboard route TTI under 4 seconds after authentication
- Backend P95 latency under 500 ms for CRUD-style endpoints
- ML-service P95 inference under 3 seconds for standard audit requests

## Review Cadence

- Reassess targets on each meaningful product or model expansion
- Pair load-test evidence with production telemetry before raising thresholds
