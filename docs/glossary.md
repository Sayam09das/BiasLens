# Glossary

- Audit: A reviewable analysis of a resume or hiring-related artifact in BiasLens
- Counterfactual: A minimally changed input used to test prediction stability
- Explainability: Techniques used to show which signals affected a model outcome
- Fairness metric: A quantitative measure used to inspect disparities or instability
- Proxy attribute: A feature correlated with protected characteristics
- SLO: Service level objective used to guide operational reliability
