# BiasLens Frontend

Production-oriented Next.js frontend for BiasLens. This app powers the public website, authentication flows, dashboard, audits, fairness views, explainability monitoring, reports, and settings.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Zustand
- Framer Motion
- Recharts

## Local Development

1. Copy the environment template:

```bash
cp .env.local.example .env.local
```

2. Install dependencies:

```bash
npm install
```

3. Start the dev server:

```bash
npm run dev
```

The app runs on `http://localhost:3000`.

## Environment Variables

Use:

- `.env.local.example` for local development
- `.env.example` for production-style/shared configuration

Important variables:

- `NEXT_PUBLIC_APP_URL`
- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_APP_ENV`
- `NEXT_PUBLIC_SENTRY_DSN`
- `SENTRY_DSN`
- `STRIPE_WEBHOOK_SECRET`
- `ML_WEBHOOK_SECRET`
- `INTERNAL_METRICS_SECRET`

## Quality Checks

```bash
npm run lint
npm run typecheck
```

## Docker

Build:

```bash
docker build -t biaslens-client .
```

Run:

```bash
docker run --rm -p 3000:3000 --env-file .env.local biaslens-client
```

## Notes

- `eslint.config.mjs` is the active ESLint v9 flat config.
- `.eslintrc.json` is included for compatibility with tools that still expect it.
- Sentry config files are scaffolded and ready to wire to `@sentry/nextjs` once that SDK is installed.
- The repo currently uses `npm` and `package-lock.json`; I did not fabricate a `pnpm-lock.yaml` because that should be generated by the actual package manager, not hand-written.
